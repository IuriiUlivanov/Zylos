# План разработки мобильного приложения: Навигатор Нови-Сад (Android)

## 1. Общие сведения и архитектура системы

### 1.1. Назначение и платформы
* **Платформа:** Android (Kotlin).
* **Целевой регион:** Нови-Сад, Сербия (с возможностью масштабирования на другие города).
* **Ключевой функционал:** 
  * Высокопроизводительная векторная карта с возможностью вращения, наклона и перемещения (работает в оффлайн-режиме).
  * Поиск по адресам и названиям организаций (на кириллице и латинице).
  * Просмотр информации об организациях, находящихся в конкретном здании (при тапе на здание).
  * Расчет оптимальных маршрутов общественного транспорта (городские автобусы + пешеходные отрезки).

### 1.2. Архитектура системы
* **Мобильный клиент (Android):** 
  * Паттерн: Clean Architecture + MVI/MVVM.
  * Графический движок: **MapLibre GL Native Android SDK** (на базе OpenGL ES / Vulkan).
  * Локальное хранилище: **SQLite / MBTiles** (хранение векторной оффлайн-подложки) + **Room** (кэширование POI, истории поиска и избранного).
* **Бэкенд-инфраструктура:**
  * **API Gateway:** Маршрутизация запросов, сжатие данных (Brotli/Gzip), авторизация.
  * **POI Service:** Выдача информации о компаниях в здании по гео-координатам или ID полигона.
  * **Routing Service:** Сервер на базе **OpenTripPlanner (OTP)** или **Valhalla** для построения мультимодальных маршрутов.
  * **Search Service:** Поисковый сервис на базе **Pelias** (геокодер с поддержкой поиска по опечаткам и альтернативным названиям).

## 2. Источники данных

| Компонент | Первичный источник | Альтернатива / Резерв |
| :--- | :--- | :--- |
| **Геометрия карты** | **OpenStreetMap (OSM)** — дамп Сербии (`Geofabrik`), обрезанный по границам Нови-Сада. | — |
| **Общественный транспорт** | **GTFS-фид JGSP Novi Sad** (расписания, маршруты, остановки автобусов). | *Transitland* / Ручная сборка открытых расписаний. |
| **Организации и POI** | **Google Places API** (категории, часы работы, контакты, отзывы). | **Overpass API (OSM)** + собственная база данных. |
| **Адресная база** | **OSM Nominatim / Pelias** (словарь улиц и домов с поддержкой латиницы и кириллицы). | — |

## 3. Технологический стек

* **Мобильная разработка:** Kotlin (Android Native).
* **Движок рендеринга:** MapLibre GL Native Android SDK.
* **Формат векторных тайлов:** Mapbox Vector Tiles (MVT).
* **Генерация оффлайн-карт:** Planetiler / Tilemaker (`.osm.pbf` → `.mbtiles`).
* **Бэкенд:** Go (Golang) или Rust (для высокой скорости гео-вычислений).
* **База данных бэкенда:** PostgreSQL + PostGIS, Redis (внутрипамятный кэш).
* **Сетевой протокол:** REST / gRPC, JSON / Protocol Buffers.

## 4. Поэтапный план разработки

### Этап 1: Подготовка данных и ГИС-инфраструктуры
1. Скачивание и фильтрация OSM-данных для Нови-Сада и ближайших пригородов (Петроварадин, Сремска-Каменица, Футог).
2. Настройка инструмента **Planetiler** для сборки вектора города в оффлайн-файл `novisad.mbtiles` (уровни масштабирования zoom 0–16).
3. Валидация GTFS-данных городского перевозчика JGSP Novi Sad.
4. Развертывание PostgreSQL + PostGIS с поддержкой spatial-индексов `GIST`.

### Этап 2: Разработка бэкенд-сервисов
1. **POI Service:** Разработка API для получения списка организаций в здании по координатам или $OSM\_ID$ с кэшированием запросов к Google Places в Redis.
2. **Routing Service:** Настройка OpenTripPlanner, импорт дорожного графа OSM и автобусного расписания GTFS.
3. **Search Service:** Поднятие Pelias для мультиязычного поиска с учетом специфики сербской топонимики.

### Этап 3: Разработка Android-клиента (Оффлайн-карта)
1. Интеграция MapLibre GL Native в Android-проект.
2. Размещение файла `novisad.mbtiles` в папке `assets` приложения (или разработка фонового загрузчика).
3. Создание кастомного стиля (Style JSON) с поддержкой 3D-выдавливания зданий (`fill-extrusion`), векторной типографики и иконок.
4. Настройка жесткого управления камерой: свайпы, поворот 360°, наклон (pitch), ограничения FPS (60 FPS) для защиты от перегрева и экономии батареи.

### Этап 4: Интерактивность и карточка организации
1. Настройка обработки тапа по экрану с помощью `queryRenderedFeatures` для выбора полигона здания.
2. Реализация динамической подсветки выбранного здания.
3. Создание выдвигающегося экрана (Bottom Sheet) с детализацией компаний: название, категории, часы работы, контактные данные.

### Этап 5: Поиск и Маршрутизация транспорта
1. Реализация поискового интерфейса с подсказками (Autocomplete).
2. Интеграция построения маршрута (точка А → точка Б):
   * Отображение пешеходных участков пунктиром.
   * Отображение автобусных линий цветными полосами с номерами маршрутов (например, №1, №4, №7, №11A).

### Этап 6: Оптимизация и тестирование
1. Профилирование производительности и плавности рендеринга на распространенных в Сербии бюджетных смартфонах (Samsung Galaxy A-серии, Xiaomi Redmi).
2. Тестирование работы базовой карты без подключения к интернету (Airplane Mode).
3. Минимизация размера `.mbtiles` файла и оптимизация ресурсов памяти.

### Этап 7: Масштабируемость и релиз
1. Абстрагирование конфигурации геоданных по `city_id` для последующего добавления новых городов (Белград, Ниш и др.).
2. Создание интерфейса управления оффлайн-картами разных регионов.
3. Публикация первой версии приложения в Google Play.
